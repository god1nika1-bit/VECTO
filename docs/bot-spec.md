# VECTO BOT — Спецификация MVP (без AI API)

## КОНЦЕПЦИЯ

Простой Telegram-бот, который ведёт клиента по заготовленной цепочке вопросов с inline-кнопками. Без подключения AI API. Логика разветвления — хардкод на Python.

## ТОЧКИ ВХОДА

### 1. С калькулятора сайта (deeplink с параметрами)
```
https://t.me/vecto_studio_bot?start=landing_bot_40000
```
Формат: `?start={services}_{total}`
- services — коды через `_`: landing, bot, content, finmodel, copy, consult
- total — сумма из калькулятора

**Поведение:** Бот парсит параметры и начинает с подтверждения:
```
Привет! 👋

Вижу, вы выбрали на сайте:
✅ Лендинг
✅ Telegram-бот
💰 Ориентировочно: 40 000 ₽

Всё верно? Давайте уточним детали, чтобы я передал
вашу заявку эксперту.

[Да, всё верно ✓]  [Хочу изменить]
```

### 2. Прямой вход (без параметров)
```
Привет! 👋 Это VECTO — мы делаем сайты, ботов, контент-системы
и финмодели для бизнеса.

Чем могу помочь? Выберите, что вас интересует:

[🖥 Сайт]  [🤖 Бот]  [📈 Контент]
[💰 Финмодель]  [✍️ Копирайтинг]  [💬 Консультация]
[🤔 Пока не знаю — помогите разобраться]
```

## БЛОК 1: О БИЗНЕСЕ (обязательный)

### Вопрос B1: Ниша
```
Расскажите в двух словах — чем занимается ваш бизнес?

Можете выбрать из списка или написать свой вариант:

[🍕 Общепит/кафе]  [💇 Салон/барбер]  [🏋️ Фитнес]
[🛒 Интернет-магазин]  [🏗 Строительство/ремонт]  [📚 Образование]
[💻 IT/Digital]  [⚕️ Медицина/здоровье]  [📦 Услуги для бизнеса]
[✏️ Другое (напишу)]
```

**Зачем:** Определяет отрасль → влияет на рекомендации и специфику вопросов. Мне важно понимать рынок клиента до начала анализа.

### Вопрос B2: Целевой клиент
```
Кто ваш типичный клиент? Кто обычно покупает / обращается?

[👤 Физлица (B2C)]  [🏢 Бизнесы (B2B)]  [👥 И те, и те]
```

Если B2C → дополнительно:
```
Примерный портрет: возраст, пол, доход?

[Молодёжь 18-25]  [Средний возраст 25-45]  [45+]
[Смешанная аудитория]  [✏️ Напишу подробнее]
```

**Зачем:** ЦА определяет тон сайта, визуал, каналы продвижения. Без этого я делаю сайт вслепую.

### Вопрос B3: Текущие каналы
```
Откуда сейчас приходят клиенты?

Можно выбрать несколько:

[📣 Сарафан/рекомендации]  [📱 Instagram/VK]
[🗺 Яндекс.Карты/2ГИС]  [🔍 Поиск Google/Яндекс]
[📢 Платная реклама]  [🤝 Партнёры]
[❌ Пока нет клиентов]  [✏️ Другое]
```

**Зачем:** Понимаю текущую воронку. Если нет онлайн-каналов — сайт критически важен. Если есть реклама без сайта — клиент теряет деньги прямо сейчас.

### Вопрос B4: Главная боль
```
Что сейчас больше всего не устраивает? Какую проблему хотите решить?

[😤 Нет сайта — клиенты не находят]
[📉 Сайт есть, но не работает]
[🤖 Нет автоматизации — всё вручную]
[📝 Нет контента — невидим в интернете]
[📊 Не понимаю свои цифры]
[🚀 Хочу масштабироваться]
[✏️ Своя проблема (напишу)]
```

**Зачем:** Главная боль = главный аргумент в моём коммерческом предложении. Это то, вокруг чего строится весь проект.

## БЛОК 2: О ПРОЕКТЕ (обязательный)

### Вопрос P1: Что нужно (если не определено)
Пропускается, если клиент пришёл с калькулятора или уже выбрал услуги на входе.
```
Что из этого вам нужно? Можно выбрать несколько:

[🖥 Лендинг (от 25к)]  [🤖 Telegram-бот (от 15к)]
[📈 Контент-система (от 20к)]  [💰 Финмодель (от 20к)]
[✍️ Копирайтинг (от 5к)]  [💬 Консультация (бесплатно)]
```

### Вопрос P2: Материалы
```
Что у вас уже есть? Это ускорит работу:

[✅ Логотип]  [✅ Тексты о компании]
[✅ Фото продукта/офиса]  [✅ Старый сайт]
[✅ Брендбук]  [✅ Прайс-лист]
[❌ Ничего нет — нужно с нуля]

Можете прямо сюда скинуть файлы — я сохраню.
```

**Зачем:** Если есть материалы — работа идёт быстрее и дешевле. Если нет — нужно закладывать доп. время на создание контента.

### Вопрос P3: Референсы
```
Есть примеры сайтов/ботов, которые вам нравятся?
Скиньте ссылки — мы сделаем лучше 😉

Или выберите стиль:

[🖤 Минимализм]  [🎨 Яркий и креативный]
[🏢 Строго-корпоративный]  [🔥 Современный и трендовый]
[🤷 Доверяю вашему вкусу]
```

**Зачем:** Референсы экономят 50% времени на согласованиях. Без них начинается «мне не нравится, но я не знаю что хочу».

## БЛОК 3: ПО УСЛУГАМ (зависит от выбора)

Активируются только вопросы для выбранных услуг.

### Если выбран ЛЕНДИНГ:
```
L1: Сайт нужен как визитка или для конкретного действия?

[📋 Визитка — показать что мы есть]
[📝 Заявка/запись — собирать лиды]
[🛒 Продажа — каталог + покупка]
[📱 Одностраничник для рекламы]
```

```
L2: Планируете запускать рекламу на сайт?

[Да, сразу]  [Позже]  [Нет, только органика]  [Не знаю]
```

**Зачем L1:** Определяет архитектуру сайта. Визитка и продающий лендинг — совершенно разные продукты.
**Зачем L2:** Если реклама — нужны правильные UTM, пиксели, скорость загрузки. Это влияет на стоимость.

### Если выбран TELEGRAM-БОТ:
```
T1: Что бот должен делать?

[📅 Запись/бронирование]  [🛒 Приём заказов]
[💬 Поддержка клиентов]  [📢 Рассылки]
[💳 Приём оплаты]  [✏️ Другое]
```

```
T2: Сколько примерно обращений в день ожидаете?

[1-10]  [10-50]  [50-200]  [200+]  [Не знаю]
```

**Зачем T1:** Бот для записи и бот для оплаты — разная сложность, разная цена.
**Зачем T2:** Определяет нагрузку и нужность CRM-интеграции.

### Если выбрана КОНТЕНТ-СИСТЕМА:
```
C1: Какие площадки интересуют?

[📱 Telegram-канал]  [📝 Яндекс.Дзен]
[🎬 YouTube]  [📷 VK/Instagram]
[📰 Блог на сайте]  [🤷 Не знаю — подскажите]
```

```
C2: Какой тон общения ближе?

[🎓 Экспертный]  [😊 Дружелюбный]
[🔥 Провокационный]  [🏢 Корпоративный]
```

**Зачем C1:** Каждая площадка — разный формат контента и трудозатраты.
**Зачем C2:** Тон = бренд. Если не определить сразу, будет переделывание.

### Если выбрана ФИНМОДЕЛЬ:
```
F1: Финмодель нужна для кого?

[👤 Для себя — понять цифры]
[💼 Для инвесторов/банка]
[📊 Для управления — дашборд]
```

```
F2: Есть текущие финансовые данные?

[Да, есть бухгалтерия/учёт]
[Есть примерные цифры в голове]
[Нет, стартап с нуля]
```

**Зачем F1:** Для себя и для инвестора — разные форматы, разная глубина.
**Зачем F2:** Без данных финмодель строится на гипотезах — нужно это обговорить.

### Если выбран КОПИРАЙТИНГ:
```
K1: Что за текст нужен?

[📄 Тексты для сайта]  [📝 Статья/исследование]
[📱 Посты для соцсетей]  [📧 Email-рассылка]
[📋 Описание продукта]  [✏️ Другое]
```

**Зачем:** Статья для Scopus и пост для Telegram — абсолютно разные задачи, разная цена.

## БЛОК 4: БЮДЖЕТ И СРОКИ

### Вопрос $1: Бюджет
```
Какой бюджет рассматриваете? Примерный диапазон —
чтобы я предложил оптимальный вариант:

[До 20 000 ₽]  [20-50 000 ₽]
[50-100 000 ₽]  [100 000+ ₽]
[Сначала хочу понять что получу]
```

**Зачем:** Без бюджета невозможно подобрать решение. Клиент за 20к и за 100к получают разный продукт — и оба должны быть довольны.

### Вопрос $2: Сроки
```
Есть ли привязка по срокам?

[🔥 Срочно (1-2 недели)]  [📅 В течение месяца]
[🗓 В течение 2-3 месяцев]  [♾ Без спешки]
```

**Зачем:** Срочность влияет на цену и приоритет. Если «горит» — я должен знать это ДО начала работы.

```markdown

## 🔴 КЛЮЧЕВОЕ
- **Услуги:** {список}
- **Боль:** {B4}
- **Бюджет:** {$1}
- **Сроки:** {$2}
- **С калькулятора:** да/нет (если да — {сумма})
- **Контакт:** {способ связи}

## 📋 БИЗНЕС
- **Ниша:** {B1}
- **ЦА:** {B2}
- **Каналы:** {B3}
- **Боль:** {B4}

## 🎯 ПРОЕКТ
- **Услуги:** {P1}
- **Материалы:** {P2}
- **Стиль:** {P3}

## 🔧 ДЕТАЛИ ПО УСЛУГАМ
{Блок 3 — все ответы по выбранным услугам}

## 💰 БЮДЖЕТ И СРОКИ
- **Бюджет:** {$1}
- **Сроки:** {$2}

## 📞 КОНТАКТ
- **Имя:** {имя}
- **Способ:** {Contact}
- **Telegram:** @{username} / {user_id}

## 📝 ПОЛНЫЙ ЛОГ
{Все сообщения клиента, без кнопок бота}
```

## ТЕХНИЧЕСКИЕ ДЕТАЛИ

- **Python 3.11+, aiogram 3.x**
- **Deeplink парсинг:** `start=landing_bot_40000` → split по `_`, последний элемент = сумма, остальное = услуги
- **State machine:** FSM (aiogram StatesGroup) для отслеживания этапа разговора
- **Хранение:** in-memory dict (MVP), позже — Redis/SQLite
- **Owner notification:** отправка .md файлом + краткая сводка текстом
